# ADR-0002：纯客户端游戏渐进接入

日期：2026-11-06。状态：采用。

背景：现有游戏只有客户端。已有后端具备云存档、活动与运营原型，但不能假定每款游戏已有服务端战斗、权威经济或可靠身份恢复。

决定：保留客户端本地玩法与存档，由独立桥接层读取已有 JSON 并显式导入云端。首次导入使用已有的零版本条件写入，云端存在、删除或冲突时不自动覆盖。账号/服务器/游戏共同界定 SDK 缓存归属。服务器会话发行、验证、注销统一使用环境隔离的哈希规则。

取舍：复用现有存档接口，无需新增迁移或每游戏服务。代价是客户端来源存档及事件仍不可信，不能据此向权威库存充值或认定竞技成绩。缓存升级不自动迁移旧的无归属数据，需要确认玩家选择。

后果：每个实际游戏只需适配自己的存档格式、冲突 UI 和安全身份存储；真实渠道、权威战斗和正式运营按需独立验收。多人实时服务和通用脚本引擎没有成为这次接入的依赖。
