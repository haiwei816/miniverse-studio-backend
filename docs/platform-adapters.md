# 渠道身份适配状态

Steam 与 TapTap 目前均为 **sandbox adapter**，真实平台登录未验证。没有真实平台 key、应用配置与客户端票据，所以不能满足原路线中“至少一款真实发行渠道登录”的上线验收；本次按用户允许的 mock/sandbox 范围交付。

PlatformAuth 接口将身份凭证验证与内部账号绑定分离。sandbox 凭证有 HMAC 签名、渠道、应用、主体、两分钟过期和随机 nonce；服务端事务防重放。测试凭证发行端点仅在 APP_ENV=sandbox 开放。生产模式明确返回 real_provider_not_configured，禁止回退到 mock。

绑定要求已有会话与新的渠道凭证，不自动合并两个账号。解绑要求新凭证及至少另一个绑定身份，避免移除最后的恢复入口。不同应用的主体标识不能自动当作同一人。

后续真实实现：Steam 通过官方服务端票据验证接口；TapTap 按所选登录 SDK 的服务端验证协议实现，明确 app 作用域和 union 身份策略。需要真机票据、无效/过期/撤销验证与平台应用白名单测试后才能改为已验证。平台云存档、成就与排行由每款游戏选择，后端运营奖励和跨渠道存档的权威来源需保持唯一。
