## 关键原理

1. **模块与包**：go.mod 管理模块身份和最低 Go 版本；同模块通过完整导入路径引用包。cmd/api 是可执行入口，internal 包承载内部实现。
2. **依赖方向**：main → config/app，app → config/httpserver。路由不依赖环境变量或进程退出逻辑，后续可以独立注入数据库等依赖。
3. **启动与请求生命周期**：读取并验证配置 → 绑定监听地址 → 构建路由 → Serve 接收连接 → ServeMux 分发请求 → Handler 写回响应。Serve 会持续阻塞，标准库负责并发调度请求。
4. **错误处理**：配置格式错误在监听前失败；端口占用由 net.Listen 返回错误；每层通过返回值添加上下文，main 统一报告错误并决定非零退出码。监听器通过 defer 释放；生产级关闭等待在 S0.5 加入。
5. **选择与权衡**：标准库路由足够支撑当前接口，无外部依赖；显式限制 HTTP_HOST 为 IP，减少隐式解析和误绑定行为，同时暂不支持主机名。module 使用本地名称，创建远程仓库后如需改路径需同步导入。
